# Security Policy

## Supported Versions

We recommend using the latest stable version of MeroCoffee for security updates. Below is the list of versions currently being supported with security updates:

| Version | Supported          |
|---------|-------------------|
| Latest  | :white_check_mark: |
| 1.x     | :white_check_mark: |

## Reporting a Vulnerability

We take the security of MeroCoffee seriously. If you believe you have found a security vulnerability, please report it to us responsibly.

### How to Report

1. **Email**: Send your vulnerability report to security@coffee.subashghimire.info.np
2. **Encryption**: Please use our PGP key for encrypted communications (key available upon request)
3. **Response Time**: We aim to acknowledge vulnerability reports within 24-48 hours

### What to Include

When reporting a vulnerability, please include:
- Description of the vulnerability
- Steps to reproduce the issue
- Potential impact assessment
- Any proof-of-concept code (if applicable)
- Your contact information for follow-up

### What to Expect

After submitting your report:

1. **Acknowledgment**: We'll confirm receipt of your report within 24-48 hours
2. **Assessment**: Our security team will evaluate the vulnerability
3. **Communication**: You'll receive updates on the status of your report
4. **Resolution**: Once fixed, we'll notify you and credit you (if desired) in our release notes

### Our Commitment

- We will not take legal action against researchers who responsibly disclose vulnerabilities
- We will keep your identity confidential unless you explicitly consent to being credited
- We appreciate responsible disclosure and will work with you to understand and fix the issue

## Security Best Practices

For users deploying MeroCoffee:

1. Keep your installation updated to the latest version
2. Use strong passwords and enable two-factor authentication
3. Regularly rotate API keys and secrets
4. Monitor your logs for suspicious activity
5. Follow our deployment security guidelines in the documentation

## Scope

This security policy applies to:
- The main MeroCoffee codebase
- Official integrations (ePayment gateways, email services)
- The official Docker images

Third-party plugins and integrations are governed by their respective security policies.
